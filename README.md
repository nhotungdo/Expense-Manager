## 📖 Giới Thiệu Dự Án

> **Trải nghiệm tương lai của quản lý tài chính cá nhân**

**MoneyTracker** không chỉ là một ứng dụng theo dõi chi tiêu đơn thuần, mà là trợ lý tài chính cá nhân thông minh của bạn. Được thiết kế với kiến trúc **Clean Architecture**, đảm bảo khả năng mở rộng, dễ bảo trì và hiệu suất cao. Dù bạn đang theo dõi chi tiêu hàng ngày hay quản lý ngân sách phức tạp với nhiều tài khoản, MoneyTracker đều đáp ứng được với giao diện hiện đại và thân thiện.

## 🚀 Bắt Đầu

Khởi chạy ứng dụng MoneyTracker của bạn chỉ trong vài phút.

### Yêu Cầu Hệ Thống

*   **Runtime**: [.NET 8.0 SDK](https://dotnet.microsoft.com/download)
*   **Database**: SQL Server 2019 trở lên (hoặc SQL Server Express)
*   **IDE**: Visual Studio 2022 hoặc Visual Studio Code
*   **Optional**: Docker Desktop (nếu muốn chạy bằng container)

### 📦 Cài Đặt

#### Phương Pháp 1: Cài Đặt Thủ Công (Khuyến Nghị) 🛠️

1.  **Clone Repository**
    ```bash
    git clone https://github.com/nhotungdo/Expense-Manager.git
    cd Expense-Manager
    ```

2.  **Cấu Hình Database**
    ```bash
    cd MoneyTrackerApp/MoneyTrackerApp
    ```
    
    Mở file `appsettings.json` và cập nhật connection string:
    ```json
    {
      "ConnectionStrings": {
        "DefaultConnection": "Server=localhost;Database=ExpenseManager;Trusted_Connection=True;TrustServerCertificate=True;"
      }
    }
    ```

3.  **Tạo Database**
    
    Sử dụng SQL script có sẵn:
    ```bash
    # Chạy file Database_Schema.sql trong SQL Server Management Studio
    # hoặc sử dụng Entity Framework Migrations:
    dotnet ef database update
    ```

4.  **Cấu Hình Google OAuth (Tùy Chọn)**
    
    Trong `appsettings.json`, thêm thông tin Google OAuth:
    ```json
    {
      "Authentication": {
        "Google": {
          "ClientId": "your-client-id",
          "ClientSecret": "your-client-secret"
        }
      }
    }
    ```

5.  **Cấu Hình Email Service (Tùy Chọn)**
    
    Cấu hình SMTP để gửi email:
    ```json
    {
      "EmailSettings": {
        "SmtpServer": "smtp.gmail.com",
        "SmtpPort": 587,
        "SenderEmail": "your-email@gmail.com",
        "SenderPassword": "your-app-password"
      }
    }
    ```

6.  **Chạy Ứng Dụng**
    ```bash
    dotnet run
    ```
    
    Ứng dụng sẽ chạy tại: `https://localhost:5000` 

#### Phương Pháp 2: Docker (Nhanh Chóng) ⚡

```bash
# 1. Clone repository
git clone https://github.com/nhotungdo/Expense-Manager.git
cd Expense-Manager

# 2. Chạy Docker Compose
docker-compose up -d

# 3. Truy cập ứng dụng
# Application: https://localhost:5000
# SQL Server: localhost:1433
```

## ⚡ Hướng Dẫn Sử Dụng

### Đăng Ký & Đăng Nhập

1. Truy cập trang chủ và nhấn "Đăng ký"
2. Đăng ký bằng Google OAuth hoặc email
3. Hoàn thành quy trình onboarding để thiết lập hồ sơ tài chính

### Quản Lý Tài Khoản

- **Thêm tài khoản mới**: Vào `/Wallets/Create`
- **Xem danh sách**: Vào `/Wallets/Index`
- **Chuyển tiền**: Sử dụng tính năng Transfer giữa các tài khoản

### Ghi Nhận Giao Dịch

- **Thêm thu nhập/chi tiêu**: Vào `/Transactions/Create`
- **Quét hóa đơn**: Sử dụng tính năng OCR để tự động nhận diện
- **Xem lịch sử**: Vào `/Transactions/Index` với bộ lọc mạnh mẽ

### Quản Lý Ngân Sách

- **Tạo ngân sách**: Vào `/Budgets/Create`
- **Theo dõi**: Dashboard hiển thị % sử dụng ngân sách
- **Cảnh báo**: Nhận email khi vượt 80% ngân sách

### Chi Tiêu Nhóm

- **Tạo nhóm**: Vào `/Groups/Create`
- **Mời thành viên**: Thêm bạn bè qua email
- **Chia sẻ chi phí**: Tự động tính toán ai nợ ai bao nhiêu

### Phân Tích AI

- **Xem insights**: Vào `/Analysis/Index`
- **Dự đoán chi tiêu**: AI phân tích xu hướng và đưa ra dự báo
- **Gợi ý tiết kiệm**: Nhận lời khuyên tài chính cá nhân hóa

## 🛠️ Công Nghệ & Thư Viện

### Backend
- **Framework**: ASP.NET Core 8.0 (Razor Pages)
- **ORM**: Entity Framework Core 8.0
- **Database**: SQL Server 2022
- **Authentication**: ASP.NET Core Identity, Google OAuth 2.0
- **Real-time**: SignalR
- **AI**: Google Gemini API
- **Email**: MailKit, MimeKit
- **Payment**: VNPay SDK
- **OCR**: Tesseract OCR

### Frontend
- **UI Framework**: Bootstrap 5
- **Charts**: Chart.js
- **Icons**: Font Awesome
- **JavaScript**: Vanilla JS, jQuery
- **Real-time**: SignalR Client

### DevOps
- **Version Control**: Git, GitHub
- **CI/CD**: GitHub Actions (planned)
- **Containerization**: Docker, Docker Compose
