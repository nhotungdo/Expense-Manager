# User Guide - Modern Dashboard

## 🎯 Overview

The redesigned dashboard provides a comprehensive view of your financial data with interactive pie charts and modern visualizations.

## 📊 Dashboard Components

### 1. Financial Summary Cards

Located at the top of the dashboard, these cards show your key financial metrics:

#### Total Income Card (Green)
- **Icon**: Down arrow (💰)
- **Shows**: Total income for the selected period
- **Change Indicator**: Percentage change from previous period
- **Color**: Green (#10b981)

#### Total Expense Card (Red)
- **Icon**: Up arrow (💸)
- **Shows**: Total expenses for the selected period
- **Change Indicator**: Percentage change from previous period
- **Color**: Red (#ef4444)

#### Net Income Card (Blue)
- **Icon**: Equals sign (=)
- **Shows**: Income minus expenses
- **Change Indicator**: Percentage change from previous period
- **Color**: Blue (#3b82f6)

#### Total Balance Card (Purple)
- **Icon**: Wallet (👛)
- **Shows**: Combined balance across all accounts
- **Info**: "All accounts" label
- **Color**: Purple (#8b5cf6)

**Interaction**: Hover over any card to see a lift animation and enhanced shadow.

### 2. Transaction Types Pie Chart

**Purpose**: Visualize the distribution of your transaction types

**Features**:
- **Income**: Green segment showing total income
- **Expense**: Red segment showing total expenses
- **Transfer**: Blue segment showing transfers between accounts
- **Percentages**: Displayed on legend labels
- **Interactive**: Hover over segments for detailed information

**Tooltip Information**:
- Amount in VND
- Number of transactions
- Percentage of total

**Summary Section**:
- Total amount across all types
- Highest transaction type

**How to Use**:
1. Hover over any segment to see details
2. Click the refresh button (↻) to reload data
3. View the summary below for quick insights

### 3. Category Spending Pie Chart

**Purpose**: Show your spending breakdown by category

**Features**:
- **Top 8 Categories**: Most significant spending categories
- **Color-Coded**: Each category has a unique color
- **Percentages**: Shown on legend labels
- **Interactive**: Hover for detailed breakdown

**Tooltip Information**:
- Category name and icon
- Amount spent
- Percentage of total spending
- Number of transactions

**Summary Section**:
- Total spending amount
- Highest spending category

**How to Use**:
1. Hover over segments to see category details
2. Compare sizes to understand spending patterns
3. Use the summary to identify top spending areas
4. Click refresh to update data

### 4. Income vs Expense Trend Chart

**Purpose**: Track your financial trends over time

**Features**:
- **Line Chart**: Shows monthly income and expense trends
- **Gradient Fill**: Visual area under each line
- **Data Points**: Hover to see exact amounts
- **Smooth Curves**: Easy to follow trends

**Legend**:
- Green line: Income
- Red line: Expenses

**How to Use**:
1. Hover over data points to see exact values
2. Compare income and expense lines
3. Identify trends and patterns
4. Use for financial planning

### 5. Recent Transactions

**Purpose**: Quick view of your latest transactions

**Features**:
- **Transaction List**: Last 5 transactions
- **Category Icons**: Visual identification
- **Color Coding**: Green for income, red for expenses
- **Notes**: Transaction descriptions

**Information Displayed**:
- Category name and icon
- Transaction note
- Amount with +/- indicator
- Date and time

**How to Use**:
1. Click on any transaction to view details
2. Scroll to see more transactions
3. Click "View All" to see complete list

### 6. AI Suggestions

**Purpose**: Smart recommendations based on your spending patterns

**Features**:
- **Personalized Tips**: Based on your data
- **Priority Levels**: High, medium, low
- **Categories**: Spending, savings, investment

**How to Use**:
1. Review suggestions regularly
2. Click "View More" for detailed advice
3. Implement recommendations to improve finances

### 7. Financial Alerts

**Purpose**: Important notifications about your finances

**Features**:
- **Budget Warnings**: When approaching limits
- **Bill Reminders**: Upcoming due dates
- **Severity Levels**: Info, warning, danger

**How to Use**:
1. Check alerts daily
2. Take action on warnings
3. Set up notifications for important alerts

### 8. Accounts Overview

**Purpose**: Quick view of all your accounts

**Features**:
- **Account Cards**: Visual representation
- **Balance Display**: Current balance
- **Color Coding**: Each account has unique color
- **Icons**: Account type indicators

**Account Types**:
- 💰 Cash: Physical money
- 🏦 Bank: Bank accounts
- 📱 E-Wallet: Digital wallets
- 🐷 Savings: Savings accounts

**How to Use**:
1. Click on any account to view details
2. Hover to see lift animation
3. Click "Manage" to add/edit accounts

## 📊 Understanding the Charts

### Pie Chart Segments

**Size**: Represents proportion of total
**Color**: Identifies category/type
**Percentage**: Shows exact proportion
**Hover**: Reveals detailed information

### Line Chart Trends

**Upward Slope**: Increasing trend
**Downward Slope**: Decreasing trend
**Flat Line**: Stable amount
**Intersection**: Break-even point

### Reading Tooltips

**Format**:
```
Category Name
Amount: XX,XXX,XXX ₫
Transactions: XX
Percentage: XX.X%
```

## 🆘 Troubleshooting

### Charts Not Loading

**Solutions**:
1. Refresh the page (F5)
2. Clear browser cache
3. Check internet connection
4. Try different browser

### Data Not Updating

**Solutions**:
1. Click refresh button on charts
2. Change period filter and back
3. Log out and log in again
4. Contact support if persists

### Slow Performance

**Solutions**:
1. Close unused browser tabs
2. Clear browser cache
3. Check internet speed
4. Update browser to latest version

### Display Issues

**Solutions**:
1. Zoom to 100% (Ctrl+0)
2. Try different screen resolution
3. Update graphics drivers
4. Use recommended browsers
